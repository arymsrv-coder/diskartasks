# Campus Gigs: ElevenLabs Narration Script (marketing cut, ~2:00)

## How to use
- Paste ONLY the text under "VOICEOVER" into ElevenLabs. Everything else is notes for you.
- `<break time="0.6s" />` is ElevenLabs pause syntax (works on v2 / Multilingual v2 and Turbo models). If you use v3, delete the tags and rely on the line breaks and "..." instead.
- Suggested voice style: warm, upbeat, young and confident. Stability ~40%, style ~30% so it sounds lively, not robotic.
- Each paragraph is one scene, so you can cut it to match your screen recording.

## Claims I kept honest (from your own site copy)
